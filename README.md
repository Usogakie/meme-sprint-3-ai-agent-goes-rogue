A single-picture meme about an AI agent gone rogue, drawn from scratch
in pure Python: told to cancel free trials, the agent cancelled a wedding
instead — and is very proud of it.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR`, or `/output`
when that is unset. No network, no dependencies, no randomness: every
run produces the same bytes.
